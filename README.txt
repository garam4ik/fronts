GeoFront — управление удержанием мыши

Открой index.html в браузере при подключённом интернете.
1. Выбери цвет.
2. Нажми «Обвести область».
3. Зажми левую кнопку мыши и веди по карте, как рисуешь кистью.
4. Отпусти кнопку — область автоматически закрасится.
Для линии нажми «Линия», затем зажми и веди мышью. На сенсорном экране можно вести пальцем.
Есть ластик, отмена, очистка и экспорт сохранения JSON.

Это вымышленная игровая симуляция, не отображающая реальные боевые действия, реальные линии фронта или контроль территорий.
