GeoFront — исправленная версия.

Открой index.html в браузере при подключённом интернете.
Чтобы обвести территорию:
1. Выбери цвет/сторону.
2. Нажми «Обвести область».
3. КЛИКАЙ по карте по точкам вдоль нужного контура (не зажимай мышь).
4. После минимум 3 точек нажми «Завершить».
Для линии — «Линия», поставь минимум 2 точки и нажми «Завершить».
Есть отмена, ластик, очистка и экспорт сохранения JSON.

Это вымышленная игровая симуляция, не отображающая реальные боевые действия, реальные линии фронта или контроль территорий. Карта подложки загружается онлайн из OpenStreetMap.
